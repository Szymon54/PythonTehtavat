# Python Programming & Data Analysis Exercises

## About This Repository
This repository contains a collection of Jupyter Notebooks (`.ipynb`) focused on Python programming fundamentals and data preparation tasks[cite: 7]. 

## Project Files
**Data Handling & Project Work**
* `GetAndKnowYourDataForTheProjectWork.ipynb`: Exploratory data analysis and familiarization with project datasets[cite: 7].

**Python Fundamentals & Exercises**
* `GuessingGame.ipynb`: A simple interactive programming exercise[cite: 7].
* `IfExercise.ipynb`: Coursework focusing on conditional logic (if/else statements)[cite: 7].
* `ListExercises.ipynb`: Practice tasks for manipulating and managing Python lists[cite: 7].
